========================================================
 实时翻译助手 · 便携包 —— 新电脑先读我
========================================================

这份文档是**给一个人在全新电脑上照着做**用的：
不假设你能上网提问、也不假设你能找到之前的聊天记录。

出任何问题，先翻到最后一节「出问题怎么办」。
实在解决不了，第六节教你怎么生成一份诊断报告。


包里已经带了**全部依赖和全部模型**，新电脑上只需要一个 Python。
（本包约 3.0 GB；代码只有 0.5 MB，其余是依赖库和语音/OCR 模型）


────────────────────────────────────────────────────
 第 0 步：确认 Python（已经装过也要跑这一遍）
────────────────────────────────────────────────────

「装过 Python 3.12」不等于 `python` 命令能用。
这是换电脑最容易卡住的地方，三个坑一个比一个隐蔽：

  · 装了多个 Python（Anaconda、微软商店版……）→ python 指向的不是 3.12
  · 勾了 Add to PATH，但当前窗口没重开    → 敲 python 说找不到命令
  · 撞上 Microsoft Store 的假 python.exe  → 敲 python 会弹应用商店

开一个**新的** PowerShell，跑这两条：

  python -c "import sys; print(sys.version); print(sys.executable); print('64-bit OK' if sys.maxsize>2**32 else '32-bit BAD!')"

  py -3.12 -c "import sys; print('py -3.12 OK:', sys.version.split()[0])"

要看到：版本号以 3.12. 开头、64-bit OK、以及 py -3.12 OK: 3.12.x

  · 第 1 条弹应用商店 / 找不到命令
      → PATH 没生效：**重开一个 PowerShell 窗口**再试；还不行就是安装时没勾
  · 版本不是 3.12
      → 装包里的  安装Python\python-3.12.9-amd64.exe
        （官方原版，已核对数字签名；安装时**务必勾 "Add python.exe to PATH"**）
  · 第 2 条失败
      → 不影响使用。启动脚本会优先找 py -3.12，找不到自动退到 python

懒得查也行：直接做第 2 步，`check_deploy.py` 会自己查版本并报错。

────────────────────────────────────────────────────
 第六节：出问题怎么办
────────────────────────────────────────────────────

【先做这件事】
  如果报错，先在目录里跑这条，把输出存下来：

      python check_deploy.py > 自检结果.txt 2>&1

  然后可以用  记事本  打开 自检结果.txt 看，或者发给别人求助。

  想要更完整的诊断报告（含 Python 路径、模型、设置、文件夹清单）：

      python tools\collect_report.py

  它会在当前目录生成  诊断报告.txt


【常见问题速查】

  双击 bat 一闪而过，什么都看不到
    → 右键 start.ps1 → 「使用 PowerShell 运行」
      它会停在窗口里显示报错，不会闪退

  提示 "Python 版本不对" / 提示需要 3.12
    → 装 3.12 64 位（见第 0 步）。程序会显示当前版本和下载地址

  提示依赖缺失（找不到 numpy 等）
    → 没拷全。`libs\` 文件夹必须**整个**拷过去（它占 460 MB，别漏）

  敲 python 弹应用商店
    → 那是 Microsoft Store 的占位符，不是真的 Python
      用 py -3.12 代替，或按第 0 步修 PATH

  杀毒 / EDR 拦截、程序被删
    → 公司电脑常见。把整个文件夹加白名单
      被拦的多半是 python.exe 的启动行为，不是文件本身

  听译没反应
    → 跑 check_deploy.py 看「系统声音回环」是否 OK
      确认扬声器真的在响（比如浏览器放个视频）

  悬浮窗是黑的 / 没字
    → 先点「① 框选区域」重新框一次

  悬浮窗拖不动
    → 「鼠标穿透」开着的时候拖不动（Windows 机制，点击会穿过去）。
      取消勾选就能直接拖；或者用主窗口那排 ◀▲▲▼▶ 挪。
      穿透开着时悬浮窗标题栏会显示「· 穿透中，拖不动」

  屏幕翻译很慢（一句一两秒）
    → 正常。没装系统语言包时用的是本地 OCR 模型（约 1300 毫秒/帧）
      提速办法见第五节

  翻译经常空白 / 报错
    → 免费在线接口会限流（尤其 MyMemory 有每日配额）
      网络能用就等一会儿；公司网络完全不通的话，把「翻译引擎」改成
      「仅本地模型」——NLLB 模型已经带在包里了（注意禁止商用许可）

  公司网络完全连不上外网
    → 界面里「翻译引擎」选「仅本地模型」，可以完全离线翻译
      （识别本来就离线）
